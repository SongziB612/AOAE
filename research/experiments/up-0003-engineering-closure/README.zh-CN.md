# UP-0003：研究工程验收，不是盈利验收

本轮交付统一验证入口、真实数据资料预检和时间切分协议。没有新增收益策略，没有下载或读取美股 ETF 价格，没有读取最终留出期，也没有接实盘。不能据此宣布“投入真实资金之前的全部工作已经完成”。

最终运行见 [verification-v3/summary.json](verification-v3/summary.json)：工程 PASS，190 项测试通过；294 次 baseline 与 144 次净专家场景评估逐字节复现，两个账户核算和净专家权重独立复算通过。真实数据预检 BLOCKED，原因 `MISSING_US_ETF_ADMISSION_MANIFEST`；资本状态 NOT_READY。上述 438 次为原实验复现，不是 438 个新增独立样本，也没有产生新的盈利证据。

## 可重复入口

在仓库根目录运行，输出必须选择一个尚不存在的子目录：

```powershell
.\.venv\python.exe scripts/verify_universal_research.py --output-dir research/experiments/up-0003-engineering-closure/verification-next --require-data-review
```

入口依次执行依赖检查、全量单元测试、UP-0001 和 UP-0002 原配置重跑、逐字节对比、两个结果的独立账户核算、净专家权重独立复算，以及真实数据资料预检。日志、输出文件哈希和结论保留在输出目录；旧结果不会覆盖。

退出码：0 表示工程通过（不代表数据已准入或可投资）；1 表示工程失败；使用 `--require-data-review` 时，2 表示工程通过但数据资料不齐。最终应同时读取 `engineering_status`、`real_data_preflight` 和 `capital_readiness`。

## 数据协议与明确缺口

`configs/universal_real_protocol.json` 固定了六个候选 ETF、训练/验证/测试时间范围、21 个交易日的 purge/embargo 要求，以及禁止研究读取的未来留出区间。它是数据准入协议，不是完整策略预注册：实际交易日切分、候选算法冻结、成本校准及统计检验方案尚未实现，必须在对应实验前补齐。

历史区间仅是预定的开发/评估分区；不能因文件里叫 test 就声称全研究历史未受污染。六只存续 ETF 是今天指定的固定样本，不能推断没有幸存者偏差。未来留出期不是“需要等到该日才开始所有研究”，也不是承诺的资金投入日期；历史数据工作可以立即进行。若候选未在首个合格观测前冻结，必须另设未来区间，不能追认已经看过的数据为最终留出。

本地现有数据目录为沪深 ETF、国债收益率和预测市场；本主线的 `data/admitted/up_us_etf/manifest.json` 缺失。既有沪深 ETF 成交重放和分红核对资产不同，不得冒充上述六只 ETF 的准入资料。

预检所需 manifest 结构：

```json
{
  "protocol_id": "UP-REAL-0001",
  "universe": ["SPY", "QQQ", "IWM", "TLT", "GLD", "DBC"],
  "evidence": {
    "raw_bars": {"path": "仓库内相对路径", "sha256": "64位小写摘要", "source": "实际来源"}
  }
}
```

`evidence` 必须同时提供协议列出的七类资料：原始行情、公司行动、可用时间/历史版本、交易日历、成立与选样证据、研究使用权限、执行费用依据。**字段齐全只意味着可以进入独立资料审核**：预检不读取证据内容，不核实所填哈希、许可或时点真实性，永不自动批准数据，更不批准交易。

## 尚未完成的必要工作

1. 获取并独立核对这六只 ETF 的合格数据与公司行动；当前没有这些已准入数据。
2. 将日历、次日执行、整股、分红应收/到账、可成交量与真实费用接入本 UP 主线。现有合成相对价格引擎不能直接宣称支持真实执行。
3. 冻结候选及家族检验规则，完成净收益、回撤、因子暴露、有效样本量与简单基准的真实历史比较。没有证据就不增加 Kelly/状态模型。
4. 独立前向成交验证、风险与容量审核，以及账户和资本授权。无法用历史回测制造尚未发生的成交。

这些缺口既包含数据供应，也包含后续实现；不应统称为“只要等”。本轮没有穷尽数据供应商或完成上述四项。

## 首轮失败保留

`verification-v1` 与 `verification-v2` 保留了 Windows 临时目录访问/清理权限失败。最终单元测试改为对文件边界做模拟，并断言预检只读取 manifest、绝不读取封存的价格证据；集成运行则使用真实仓库完成缺失资料检测。没有放宽数据检查，也没有忽略测试错误。

## 第一性原理复核

没有识别出新增经济付款方。UP 重分配并不自动产生风险溢价以外的 alpha；交易成本由账户承担。UP-0002 的净评分机制仍不通过原筛选，失败保留。当前独立真实样本外收益、可执行净优势及未来破产概率均未知。再复杂的模型也不能替代这些缺失证据。
