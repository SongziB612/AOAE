# Outcome-based agent instructions

## Decision

Update repository work instructions, not trading-model weights or model selection. The supplied article concerns agent prompting and skills. Official OpenAI Docs was used to verify the matching article: Eric Provencher, [Rethinking skills and prompts for GPT-6 Astra](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra), September 11, 2026.

The adopted principles are narrow task routing, explicit safe autonomy, outcome-based completion and proportionate verification. They do not grant financial authority or establish a quantitative edge.

## Audit and changes

- The root AGENTS.md already had valuable financial evidence boundaries. Preserve them, including the existing user-added first-principles challenge.
- Replace the unconditional nine-stage itinerary with completion criteria and risk-based checks. Inspection, testing and review remain required when relevant, without repeating the whole pipeline for prose changes.
- Remove a dated Phase 1.3 status paragraph from always-loaded instructions. Its historical structural research remains in README and experiment evidence; its failed fills and minimum-sample conditions are not overturned by this edit.
- Route manual execution and pre-capital work to their own documents. Lack of MTAIC must not be treated as blocking all local research or manual preparation.
- State that relevant, safe local work should continue through actual output verification; distinguish unresolved local work from external waiting instead of requesting approval after every small step.

The inspected repository instruction search found root AGENTS.md and no repository SKILL.md outside excluded data/environments/cache areas. No new skill was warranted. Globally installed skills, system instructions, provider model settings and credentials were not modified. This is not a model-weight upgrade, fine-tune, or change to the frozen ETF strategy.

## Verification and limits

The integrated pre-capital implementation immediately preceding this instruction change passed 304 unit tests plus scripts/verify.ps1, including dependency, deterministic reproduction and independent reference audits. Documentation changes do not require repeating unchanged quantitative results. The new journal bridge has separate targeted checks and is paper-only.

No claim of improved profitability, reduced wall time or model quality is made without subsequent task-level comparison. Evaluate future behavior by fewer unnecessary approvals and repeated full-suite runs, successful end-to-end artifacts, and unchanged evidence/authorization boundaries—not by instruction length alone.
